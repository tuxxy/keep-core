# Batch-13 controls (tuxxy/keep-core#142, FSM analysis R-1)

Run in a scratch worktree only (`B13-tests/keep-core-ctl`, detached at `de1e99f0`, never pushed), with the runner's `LEGACY_*` environment:
`run-control.sh <scratch> <patch or none> <log>`. It copies `pkg/tbtc/frost_redemption_b13_test.go` and `pkg/tbtc/frost_redemption_b13_export_test.go` in, applies the patch to production code, runs `TestFrostRedemptionLeaderMatchesFollower` (five cases, `-parallel 5`), then reverses the patch and removes the copies.

The patches are controls, not fixes. Patches `b13-review-*` are the reviewer's (`REVIEW-TEST-B13.md`), copied unchanged. Leader-side patches touch `pkg/tbtcpg/redemptions.go` (`findPendingFrostRedemptions`) or `pkg/chain/ethereum/frost_node.go` (`PendingFrostRedemptions`); the follower-side patch touches `pkg/frost/redemption/planner.go` (`redeemable`).
